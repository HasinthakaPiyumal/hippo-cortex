# stage1_imagenet_r

ImageNet-R continual-learning benchmark — harder and more diverse than Split-CIFAR100; tests whether HippoCortex generalises beyond a single-dataset split.

## Goal

Show the same constant-memory advantage and a comparable accuracy gain pattern over Mamba-CL and Inf-SSM on a domain-shifted, class-incremental stream.

## Outputs

Runs write to `../../results/stage1_imagenet_r/<run_id>/`.
